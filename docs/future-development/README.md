# Future development

This directory contains approved planning documents for capabilities that are
not part of the current SpartanCode implementation scope.

## Game development expansion

The complete documentation-only plan is [GAME_DEVELOPMENT_EXPANSION.md](../GAME_DEVELOPMENT_EXPANSION.md).
It defines premium native-engine PC and console production as the quality
target, with browser/2D tooling limited to optional planning and validation,
mobile-only authoring, all supported operating-system targets, agent roles
under Leo, asset and plugin safety, testing, release gates, and phased
decision points.

No game-development implementation is authorized by that plan until its Phase
0 architecture contract is separately approved.

## Extension and connector compatibility

The major coding-program interoperability specification is
[EXTENSION_CONNECTOR_COMPATIBILITY.md](../EXTENSION_CONNECTOR_COMPATIBILITY.md).
It covers VS Code-compatible tools, JetBrains and Android Studio, Visual
Studio, Eclipse, Xcode, Neovim/Vim, Emacs, Sublime, Zed, terminal coding
agents, and developer-service connectors. It defines capability reporting and
does not claim that a generic adapter replaces a vendor's official toolchain.
